Hosting

Hosting Relaytour

Relaytour runs on a server. Your organization can install it on its own server, or entrust this task to a host. All the software’s features remain available in both cases.

Install Relaytour Compare the two ways to use Relaytour
Official host

Relaytour Cloud

Relaytour Cloud offers an installation reserved for each organization, on a server located in France. Subscriptions to Relaytour Cloud fund the development of the free software.

Relaytour hosted for you

The Relaytour Cloud team installs Relaytour, updates it, backs it up and sends its emails. Your organization uses it at your-organization.relaytour.app or at its own domain.

Discover Relaytour Cloud

Personalized support

The Relaytour Cloud team can also install Relaytour on your organization’s server and support it afterwards. It can take over your documents, import your content and train your admins.

Commitments

Relaytour Cloud’s commitments

Relaytour Cloud is the project’s official host. The owner of the Relaytour trademark grants it this status through a trademark license. The Relaytour Cloud team meets the following commitments.

Code

The published code, without private patches

The Relaytour Cloud team deploys the image published by the project. It runs no privately modified version.

License

Published modifications

If the Relaytour Cloud team modifies the software, it publishes its modifications, as section 13 of the AGPL-3.0 license requires.

Data

Data handed over on request

The Relaytour Cloud team hands an organization the export of its content and a backup of its database. The organization can then change host or host itself.

Trademark

The trademark policy

The Relaytour Cloud team follows the project’s trademark policy, which applies in the same way to every host.

Other hosts

Hosting Relaytour for others

Any host can host Relaytour for others under its own name, without asking for permission. The trademark policy (in French) sets out how to use the name and the logo. Only the official host can present itself as linked to the project.
