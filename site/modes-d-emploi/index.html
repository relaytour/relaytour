Les modes d'emploi de Relaytour

Chaque mode d'emploi décrit les écrans et les actions d'un rôle. Choisissez celui qui correspond au rôle que votre organisation vous a donné.

Un mode d'emploi ne décrit que les fonctions propres à son rôle. Les admins consultent aussi le mode d'emploi des référentes et référents, qui présente les écrans communs à toutes les personnes.

Référent·e

Suivre vos tâches et vos fiches

Pour toute personne affectée à un périmètre : la connexion, Mon espace, le rétroplanning, les fiches et les préférences.

Lire le mode d'emploi Admin d'une activité

Piloter une activité

Pour les personnes qui administrent un événement, une section ou une instance : périodes, périmètres, équipe et avancement.

Lire le mode d'emploi Admin de l'organisation

Tenir l'organisation

Pour les membres du bureau : l'identité de l'organisation, ses activités, les comptes et les rôles.
