# Nom et identité visuelle

La licence AGPL-3.0 couvre le code de Relaytour. Elle ne couvre ni le nom « Relaytour », ni le pictogramme aux deux arcs, ni les fichiers qui les portent (`packages/orga/public/favicon.svg`, `favicon.png`, `icon*.png`). Ces éléments restent la propriété de Quentin Fremeaux.

## Ce que vous pouvez faire sans demander

- Installer et héberger Relaytour tel que publié, avec son nom et son pictogramme, pour votre organisation ou pour des tiers.
- Dire que votre installation ou votre service utilise Relaytour, par exemple « propulsé par Relaytour ».
- Citer le nom dans un article, une documentation, une comparaison ou une formation.

## Ce qui demande un autre nom

- Une version modifiée du logiciel distribuée ou hébergée sous le nom Relaytour, avec son pictogramme.
- Un produit, un service ou un nom de domaine qui reprend le nom ou le pictogramme d'une manière qui laisse croire à un lien avec le projet.

Dans ces cas, vous choisissez un nom et une identité visuelle distincts. Le crédit « propulsé par Relaytour » reste possible et ne vaut pas autorisation d'utiliser le pictogramme comme identité de votre service.

## Crédit dans les mails

Les mails envoyés par l'application portent en pied de page la mention « propulsé par Relaytour, logiciel libre » avec le lien du dépôt. Nous vous remercions de la conserver. La licence ne l'impose pas.
